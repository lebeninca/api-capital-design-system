Estados

Nenhum elemento clicável entra na peça sem os cinco estados. Cada um se mostra sempre do mesmo jeito, em todo componente.

Os cinco estados

EstadoComo se mostra
NormalA cor de papel do elemento
SobreEscurece 18%. O cursor vira mão
FocoAnel de 3 px, afastado 2 px. Chega pelo teclado
CarregandoO rótulo troca e o elemento trava
