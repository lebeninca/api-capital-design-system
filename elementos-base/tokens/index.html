Tokens

Todo valor do sistema (cor, tipografia, espaço, forma) vive em uma folha única de estilo. Consuma o token, nunca escreva o valor.

Passo 1: importar a folha

Uma linha traz o sistema inteiro: as fontes (@font-face), as variáveis e as classes de componente:

<link rel="stylesheet" href="https://design.apicapital.com.br/tokens/api-capital.css">

A folha importa fontes.css, tokens.css e componentes.css. A peça bebe do endereço, não de cópia.

Passo 2: consumir variável

Toda variável tem o prefixo --api-. Use a variável de papel, nunca o hex:

color: var(--api-texto); background: var(--api-fundo-bloco); border-radius: var(--api-canto); gap: var(--api-x6);

var(--api-acao), não #0D2A54. Valor que não existe no sistema é erro. Se faltar um, pergunte, não invente.

Passo 3: usar as classes de componente

Os componentes declarados existem como classes .api-*, e a tipografia como classes de nível:

<button class="api-botao-primario">Enviar proposta</button> <h1 class="api-display">Título de abertura</h1> <div class="api-respiro-x10 api-margem-topo-x6">…</div>

Use .api-botao-primario, não um botão novo. As classes de espaço estão em Espaçamento.
