Tudo que é preciso para produzir uma peça da API Capital dentro do padrão: a especificação, os vetos, os tokens e os ativos de marca. É deste endereço que as peças bebem — atualizou aqui, atualizou em todo lugar.

Trabalhar com o Claude

Instale uma vez e peça as peças em português, todo dia, em qualquer conversa: “faz uma proposta comercial com a cara da API Capital”.

  1. Baixe a skill no botão abaixo.
  2. No Claude, abra Configurações → Recursos → Skills e suba o arquivo .zip. Se a opção não aparecer, ligue execução de código na mesma tela.
  3. Pronto. É só pedir.
