Trabalhar com o Claude

Instale uma vez e peça as peças em português, todo dia, em qualquer conversa: “faz uma proposta comercial com a cara da API Capital”.

  1. Baixe a skill no botão abaixo.
  2. No Claude, abra Configurações → Recursos → Skills e suba o arquivo .zip. Se a opção não aparecer, ligue execução de código na mesma tela. Já tinha uma versão instalada? Apague a antiga antes de subir.
  3. Pronto. É só pedir.

A skill não guarda o design system dentro dela: lê tudo deste endereço a cada trabalho. Mudou aqui, mudou na próxima peça, sem baixar nada de novo. Ela só avisa quando a própria skill tiver versão nova.
