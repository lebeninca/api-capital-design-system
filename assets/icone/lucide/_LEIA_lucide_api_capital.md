# Lucide — biblioteca de ícones oficial da API Capital

**1.767 ícones em SVG**, versão **1.31.0**, baixados da release oficial em 2026-08-11.

Escolhida em 11/08 entre quatro bibliotecas comparadas lado a lado: traço único de
2 px, geométrico, lê bem em tamanho pequeno.

## Como usar

**Os 24 ícones já escolhidos** vivem como folha própria no `marca_api_capital_2026.pen`, no
cluster `· BASES · ÍCONES`, nomeadas `api_capital_icone_<conceito>`. Essa é a entrega — o resto
desta pasta é o estoque.

**Quando precisar de um ícone que não está entre os 24:** procura aqui pelo nome do arquivo,
e ele entra no `.pen` como nó `icon` nativo — `library: "lucide"`, `icon: "<nome-do-arquivo-sem-extensão>"`.
Não precisa importar o SVG; o Pen desenha a biblioteca nativamente.

⚠️ **Os nomes mudam entre versões do Lucide.** Três dos escolhidos já vieram renomeados:
`pie-chart` virou `chart-pie`, `bar-chart-3` virou `chart-column`, `home` virou `house`. Quando
um ícone não aparecer, o `execute` avisa `not found in the 'lucide' icon set` — conferir o nome
nesta pasta antes de concluir que o ícone não existe.
